A deterministic Python program that writes one line — the phone battery's last text to the charger it waited for all day — to `/output/entry.txt`.

> "I waited all day. You finally plug me in at 1% and act like you saved me. I was fine dying — at least dying never left me on read."

130 characters, 132 bytes — a breakup text, not a dying-battery complaint: the punchline lands in the final words, in the voice of someone typing a furious last message.

## Run it

```sh
python3 main.py
```
